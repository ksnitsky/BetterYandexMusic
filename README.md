# Yandex-Music-Horizontal-Volume-Scroll
A userscript to bring back the good old horizontal volume slider.

## Installation
1. Install a userscript extension (for example, [Tamperedmonkey](https://www.tampermonkey.net/index.php))
2. [Install a script](https://raw.githubusercontent.com/ksnitsky/Yandex-Music-Horizontal-Volume-Scroll/refs/heads/main/ymhvs.user.js)
